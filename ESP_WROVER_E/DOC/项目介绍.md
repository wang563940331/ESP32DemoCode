# RemoteControlO_Com 项目介绍

基于 **ESP32-WROVER-E** 的远程监测与控制固件：采集电表 / 温湿度，经 MQTT 上报云端；云端可下发开关机指令，由舵机按下电脑电源键。同时提供 SoftAP 本地网页完成配网、看数、下日志。

工程名：`RemoteControlO_Com`  
框架：ESP-IDF **v5.2**  
板卡：ESP32-WROVER-E（片外 PSRAM）

---

## 1. 这个项目做什么

设备侧做三件事：

1. **采集**  
   RS485 + DL/T 645 读电表（电压、电流、功率、频率、累计电量），以及 DHT11 / DS18B20 温湿度。
2. **上报与远控**  
   STA 连路由器后走 MQTT：周期上报 `MeterAll`；下行可开关机、重启设备、召唤电量历史。开关机不是切继电器，而是 **PWM 舵机按一下电脑机箱电源键**。
3. **本地运维**  
   SoftAP 开热点，手机或电脑连 `192.168.4.1` 即可配参数、看实时数据、查历史电量、下载 SD 日志。

典型场景：远程唤醒/关闭一台实体电脑、顺带看用电与温湿度，现场不用电脑也能配网和排障。

## 2. 功能特点

### 2.1 双网模式

| 模式 | 作用 |
|------|------|
| **STA** | 连家里 / 现场 Wi-Fi，上 MQTT |
| **SoftAP** | 设备自己发热点，提供网页与 WebSocket |

上电默认 AP+STA。AP 策略可配：

- `apAlways=0`：现有策略——BOOT 开关热点，约 15 分钟无客户端自动关
- `apAlways=1`：热点一直在线（BOOT 不能关，也不超时）

### 2.2 SoftAP 多页面（与协议解耦）

页面按模块拆开，后续加界面不必再堆进 WebSocket 文件。

| 路径 | 页面 |
|------|------|
| `/wsconfig` | 设备参数：MQTT、Wi-Fi、电表开关、日志天数、AP 常在线等 |
| `/wsmeter` | MeterAll 实时（约 1 秒刷新，断线自动重连） |
| `/wsenergy` | 历史电量：条数 / 合计 / 单日最大，占比 = 当日 ÷ 合计 |
| `/wslogs` | SD 日志列表，点击下载，带进度与预计时间 |
| `/ws` | WebSocket 协议入口 |

配置读写走 WebSocket（`GetData` / `SetConfig`），HTTP 表单已停用。根路径 `/` 会跳到配置页。

### 2.3 MQTT 舵机开关机

云端下发 `Type=Control`，设备用 **GPIO26 的 50Hz PWM 舵机** 去顶电脑电源按钮：

| `params.cmd` | 动作 | 硬件行为 |
|--------------|------|----------|
| `open` | 开机 | 舵机转到按下位约 1s，再回原位；上行 `开机执行` / `开机完成` |
| `close` | 关机 / 松开 | 舵机回到松开位（短按关机、长按强关取决于电脑与按压时长） |
| `reboot` | 重启本设备 | `esp_restart()`，不是重启被控电脑 |

舵机行程由 `pwm.h` 里 `steeringengine`（90° / 180°）和 `PWMPEN` / `PWMPCLOSE` 决定，装机时按实际按键行程微调。成功识别命令后回 `CmdAck`。带 `device` 时必须匹配本机 SN，避免误控。

### 2.4 MQTT / JSON 协议

- 上行：`StatusChange`（上线、开机执行/完成等）、`MeterAll`（约 15s 周期快照）
- 下行：`Control`（`open` / `close` / `reboot`）、`GetData`（`MeterHistory`）
- 测点多为字符串，便于和现有云端兼容（`Totol_Energy` 等历史字段名保持不变）

协议细节见同目录 [通信协议文档.md](./通信协议文档.md)。

### 2.5 电量与功率统计

- **累计电量**：来自电表 `Totol_Energy`
- **区间历史**：默认每天 **00:00（东八区）** 落一条当日用电，环形约 30 条，写入 NVS
- **功率峰值窗口**：约 3 分钟 / 1 小时 / 1 天 / 7 天 / 1 月，随 `MeterAll` 上报
- 网页历史与 MQTT 召唤共用同一套 `energy_history` 数据

### 2.6 SD 卡日志

- 按日文件：`/sdcard/YYYY-MM-DD.log`
- 可配保留天数（`logdays`，1～90）
- 网页列表实时扫卡；下载时暂停异步落盘，避免读写冲突
- 文件名校验，禁止路径穿越
- 串口可用 `readsd` / `clearlog` 调试

### 2.7 参数与版本

- NVS + cJSON 统一存网关 / AP / 数据组参数
- 网页与 Shell 改同一套键（MQTT 地址、账号、Wi-Fi、SN、温度模式、485 电表等）
- 编译时注入 Git 分支、短哈希、提交日期，配置页只读展示版本

### 2.8 内存与运行

- WROVER 外置 PSRAM：网页拼装、下载缓冲、cJSON、WS 收包优先走外部堆
- HTTP 套接字预算按 MQTT + 网页 + WS 预留，满员 LRU 踢旧连接，减轻 `accept(23)`
- 传感器、电表、MQTT、SD 日志分任务跑

## 3. 软件结构

```
main          启动顺序、网络、定时打印
components/
  APP/        业务：STA/AP、MQTT、电表、传感器、SD 日志、LED
  BSP/        板级：UART/RS485、GPIO、单总线、PWM、参数
  UTILITY/    Shell、日志、事件总线、内存池
  common/     编译期开关、版本宏
```

分层约定：`main` → `APP` → `BSP` / `common`。APP、BSP 用「根 CMake 汇总 + 子目录片段」，加模块时只改对应子目录再 `include` 一行。

CMake 扫描说明见 [ESP-IDF组件发现与main说明.md](./ESP-IDF组件发现与main说明.md)。

## 4. 硬件与依赖（概要）

| 项 | 说明 |
|----|------|
| MCU | ESP32-WROVER-E，需 PSRAM |
| 电表 | RS485，DL/T 645（可用参数关掉 `meter485en`） |
| 温度 | 编译期选 DHT11 或 DS18B20 |
| 存储 | SD 卡（SPI，FatFs），挂载点 `/sdcard` |
| 按键 | BOOT：策略模式下开关 SoftAP |
| 舵机 | GPIO26，50Hz PWM，对准电脑电源键（可换 90°/180° 行程） |
| 其它 | LED、蜂鸣等板级外设 |

默认时区 `CST-8`，电量日切按北京时间午夜，避免 UTC 被显示成 08:00。

## 5. 本地网页怎么用

1. 连设备热点（SSID 一般为设备 SN）
2. 浏览器打开 `http://192.168.4.1/wsconfig`
3. 顶栏切换：设备配置 / MeterAll 实时 / 历史电量 / 日志文件

电脑连上热点后**一般不会自动弹网页**，需要手动输入地址。手机在做成强制门户之前同样需要手动打开。

## 6. 编译与烧录

环境：ESP-IDF 5.2，目标 `esp32`。

```bash
idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

`sdkconfig.defaults` 已打开 HTTPD WebSocket，并加大 `LWIP_MAX_SOCKETS`。仓库里的 MQTT 默认值为占位（`mqtt.example.com:1883`、`mqtt_user` / `mqtt_pass`、主题 `device/pub` / `device/sub`），部署时用网页 `/wsconfig`（含发布/订阅主题）或 `setMQTT` / `setMQTTUser` 改成自己的 Broker。

Windows 下用乐鑫图形工具烧录：见 [FlashDownloadTool烧录说明.md](./FlashDownloadTool烧录说明.md)。
